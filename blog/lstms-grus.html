LSTMs, GRUs, and Gated Memory

Retention is a product of gate values

Direct cell-state sensitivity = 0.97^20 = 0.5438

Hold the gates fixed and follow the direct cell-state path. A gate near one can preserve sensitivity; addition alone does not guarantee memory retention. The full network derivative has other paths.

A vanilla RNN sends gradients through a long chain of state updates. Those gradients can shrink or grow across the chain, making distant dependencies difficult to learn. LSTMs add a memory path whose retention the network can control.

Hochreiter and Schmidhuber introduced the LSTM in 1997 with a separate memory state and gates controlling writes and reads. Gers, Schmidhuber, and Cummins later added a forget gate.

The equations below describe the later LSTM with a forget gate, which lets the cell reset memory on continual streams. LSTMs became widely used in NLP, speech, and time-series modeling before attention-based models became common.

The cell state highway

An LSTM keeps a separate cell state, ctc_tct​. Gates control how much of its previous value is retained, how much new information is added, and how much is exposed as the hidden state.

The vanilla RNN computes a new hidden state through a nonlinear transformation at each step. The LSTM cell-state update instead adds a gated candidate to a gated copy of the old cell state.

The scalar comparison below tracks how strongly the initial state affects a later state. Both architectures receive the same input stream; the derivative measures sensitivity to that initial state.

Here are the equations for one LSTM timestep. Each gate takes the concatenation of the previous hidden state ht−1h_{t-1}ht−1​ and the current input xtx_txt​, then applies its own learned weight matrix and bias.

Forget gate (how much of the previous cell state to retain):

ft=σ(Wf⋅[ht−1,xt]+bf)f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)ft​=σ(Wf​⋅[ht−1​,xt​]+bf​)

Input gate (how much of the new candidate to write):

it=σ(Wi⋅[ht−1,xt]+bi)i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)it​=σ(Wi​⋅[ht−1​,xt​]+bi​)

Candidate values (what new information looks like):

c~t=tanh⁡(Wc⋅[ht−1,xt]+bc)\tilde{c}_t = \tanh(W_c \cdot [h_{t-1}, x_t] + b_c)c~t​=tanh(Wc​⋅[ht−1​,xt​]+bc​)

Output gate (what part of cell state to reveal as hidden state):

ot=σ(Wo⋅[ht−1,xt]+bo)o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)ot​=σ(Wo​⋅[ht−1​,xt​]+bo​)

Then the cell state update and hidden state output:

ct=ft⊙ct−1+it⊙c~tc_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_tct​=ft​⊙ct−1​+it​⊙c~t​

ht=ot⊙tanh⁡(ct)h_t = o_t \odot \tanh(c_t)ht​=ot​⊙tanh(ct​)

The σ\sigmaσ is the sigmoid function (outputs between 0 and 1, so each gate value acts like a dial). The ⊙\odot⊙ is element-wise multiplication. The cell-state update adds the retained old state to the new candidate, scaled by the input gate.

Why addition helps gradient flow

In a vanilla RNN, the gradient flows backward through a chain of matrix multiplications, one per timestep. Repeated contraction along the Jacobian chain can shrink the gradient exponentially.

In an LSTM, the gradient can flow backward along the cell state highway via that additive update. Along the direct cell-state path, treating the gates at that timestep as fixed, ∂ct/∂ct−1=ft\partial c_t / \partial c_{t-1} = f_t∂ct​/∂ct−1​=ft​. The full Jacobian has more terms because ftf_tft​, iti_tit​, and c~t\tilde{c}_tc~t​ all depend on ht−1h_{t-1}ht−1​ and therefore indirectly on ct−1c_{t-1}ct−1​, so this is one useful path through the derivative, not the full derivative.

As long as the forget gate stays close to 1, the direct cell-state gradient decays slowly instead of being repeatedly transformed by the full recurrent matrix and the tanh derivative. That decay is still a product of forget-gate values, so a forget gate of 0.97 over 40 steps gives roughly 0.9740≈0.300.97^{40} \approx 0.300.9740≈0.30 along that path. LSTMs mitigate vanishing gradients rather than eliminating them, but the improvement can be substantial on tasks that require retaining information across many steps.

Walking through one timestep

Suppose an LSTM has processed "the cat" and now receives "sat". Its previous hidden state ht−1h_{t-1}ht−1​ depends on the preceding words; its current input xtx_txt​ is the embedding for "sat". The visualization uses chosen values to trace the gates.

In phase 1, the chosen forget-gate values are [0.9,0.1,0.8,0.7][0.9, 0.1, 0.8, 0.7][0.9,0.1,0.8,0.7]. The second coordinate retains only 10% of its previous cell-state value; the others retain 70–90%. These coordinates have no assigned linguistic meaning in this example.

In phase 2, the second coordinate receives an input-gate value of 0.8 and a candidate value of 0.9. Their product adds 0.72 to the retained cell value, replacing much of what the forget gate removed.

By phase 5, the output gate filters the updated cell state to produce the new hidden state. Dimension 3 has a high output gate (0.9), so more of that coordinate reaches the hidden state. Dimension 4 has a low output gate (0.3), keeping most of that cell state internal, which can preserve information for later steps.

A long-range dependency, slot by slot

Across a sentence, a gate can retain a feature until a later prediction needs it.

Consider subject-verb agreement with a relative clause in the middle: "the keys that the man on the bench forgot are on the table". The verb "are" has to agree with "keys" (plural), not with "man" or "bench" which are closer but irrelevant. A trained LSTM can learn mechanisms like this. In some language models, researchers have found interpretable units that track number or syntax (Lakretz et al. found long-distance number information largely managed by two "number units" in a studied LSTM, and Linzen et al. showed LSTMs capture non-trivial grammatical structure even when sequential and structural cues conflict), though real models often distribute the same information across several dimensions.

The viz below is hand-built, not trained, but it shows the mechanism. Watch the c[0] slot when "keys" arrives. The forget gate for that slot drops near zero (erase whatever was there), the input gate writes a large positive value, and from that point on the forget gate holds near 0.97 through every other token. By the time "are" arrives, the plural signal is still intact.

The GRU: a streamlined alternative

In 2014, Cho et al. proposed the Gated Recurrent Unit as a simpler alternative. The GRU merges the cell state and hidden state into a single vector and uses only two gates instead of three.

Reset gate (how much of the previous hidden state to expose when computing the candidate):

rt=σ(Wr⋅[ht−1,xt]+br)r_t = \sigma(W_r \cdot [h_{t-1}, x_t] + b_r)rt​=σ(Wr​⋅[ht−1​,xt​]+br​)

Update gate (the interpolation factor between old and new):

zt=σ(Wz⋅[ht−1,xt]+bz)z_t = \sigma(W_z \cdot [h_{t-1}, x_t] + b_z)zt​=σ(Wz​⋅[ht−1​,xt​]+bz​)

Candidate hidden state:

h~t=tanh⁡(Wh⋅[rt⊙ht−1,xt]+bh)\tilde{h}_t = \tanh(W_h \cdot [r_t \odot h_{t-1}, x_t] + b_h)h~t​=tanh(Wh​⋅[rt​⊙ht−1​,xt​]+bh​)

Final hidden state:

ht=(1−zt)⊙ht−1+zt⊙h~th_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_tht​=(1−zt​)⊙ht−1​+zt​⊙h~t​

Here z means the amount to write. Some sources, including PyTorch, use the opposite convention: z weights the old state. PyTorch also applies the reset gate after its recurrent candidate projection; check the library equations when comparing implementations.

In the final equation, the update gate ztz_tzt​ interpolates between keeping the old hidden state and adopting the new candidate. When ztz_tzt​ is close to 0, the hidden state passes through unchanged (like the LSTM's forget gate being close to 1). When ztz_tzt​ is close to 1, the old state is replaced with new information.

The GRU has no separate cell state or output gate. The update gate ztz_tzt​ is the main keep-vs-write mechanism: it decides how much old hidden state to preserve versus how much candidate state to adopt, the same job the LSTM splits between forget and input gates. The reset gate rtr_trt​ does something different: it controls how much of the previous hidden state is visible while computing the candidate, gating what counts as "context" for the new write.

Misconceptions

"LSTMs completely solve vanishing gradients." They mitigate the problem significantly, but they don't eliminate it. The gradient still flows through the forget gate at each timestep, and if the forget gate learns values consistently below 1.0, the gradient will still decay over very long sequences. Karpathy's character-level examples also showed difficulty with dependencies spanning thousands of characters.

"GRUs are always worse than LSTMs." Chung et al. found that performance depended on the task. A GRU has fewer parameters at the same hidden size, but that alone does not determine model quality or training speed.

"The forget gate decides what to forget." Its value is a retention fraction: 1 keeps the old cell value and 0 erases it. The name describes the operation it controls, rather than the direction of the gate value.

What's next

Gates help preserve information, but an encoder still has to summarize its input for a decoder. The next post, Seq2seq and Bahdanau attention, lets the decoder revisit individual source positions instead of relying on one final state.

Additional reading (and watching)

  • Hochreiter, S. & Schmidhuber, J. (1997). Long Short-Term Memory. Neural Computation, 9(8), 1735-1780. The original LSTM, with input and output gates and the constant-error cell-state path. The forget gate isn't here yet.
  • Gers, F.A., Schmidhuber, J., & Cummins, F. (2000). Learning to Forget: Continual Prediction with LSTM. Neural Computation, 12(10), 2451-2471. Added the forget gate so an LSTM cell can learn to reset itself on continual streams. This is the equation set most modern presentations call "the LSTM."
  • Jozefowicz, R., Zaremba, W., & Sutskever, I. (2015). An Empirical Exploration of Recurrent Network Architectures. ICML 2015. Found that initializing the LSTM forget-gate bias to 1 closed much of the gap between LSTM and GRU.
  • Cho, K., et al. (2014). Learning Phrase Representations using RNN Encoder-Decoder for Statistical Machine Translation. arXiv:1406.1078.
  • Chung, J., et al. (2014). Empirical Evaluation of Gated Recurrent Neural Networks on Sequence Modeling. arXiv:1412.3555.
  • Greff, K., et al. (2017). LSTM: A Search Space Odyssey. IEEE Transactions on Neural Networks and Learning Systems.
  • Karpathy, A. (2015). The Unreasonable Effectiveness of Recurrent Neural Networks. Blog post. Visualized interpretable neurons inside a character-level LSTM.
  • Radford, A., Jozefowicz, R., & Sutskever, I. (2017). Learning to Generate Reviews and Discovering Sentiment. arXiv:1704.01444. A single LSTM unit in a large language model trained on Amazon reviews turned out to track sentiment.
  • Linzen, T., Dupoux, E., & Goldberg, Y. (2016). Assessing the Ability of LSTMs to Learn Syntax-Sensitive Dependencies. TACL. Showed LSTMs capture non-trivial grammatical structure but still err when sequential and structural cues conflict.
  • Lakretz, Y., et al. (2019). The Emergence of Number and Syntax Units in LSTM Language Models. NAACL 2019. Identified two specific units in a trained LSTM that carry long-distance number information for subject-verb agreement.
  • PyTorch. GRU equations and implementation conventions. Update-gate direction and reset-gate placement.
  • OpenAI. (2019). Dota 2 with Large Scale Deep Reinforcement Learning. arXiv:1912.06680. Used a 4096-unit LSTM as the core memory of the Dota 2 agent.
  • Gu, A. & Dao, T. (2023). Mamba: Linear-Time Sequence Modeling with Selective State Spaces. arXiv:2312.00752. Selective SSMs that bring back the RNN-style recurrence while remaining parallelizable in training.
