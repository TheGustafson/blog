# Crosshair AlphaZero Training (`training/`)

Pure-JAX GPU training pipeline for `ai-crosshair`. This directory trains the two-residual-block policy-value network embedded in the Rust engine (`src/networks/az-default.bin`) from self-play trajectories generated by `selfplay`.

## Contents

- `model.py`: Two-residual-block MLP (`INPUTS = 294`, `HIDDEN = 128`, `ACTIONS = 49`, `VALUE_HIDDEN = 32`, `PARAM_COUNT = 114,290`), forward/inference passes with IEEE-754 `float32` matmul precision (`jax_default_matmul_precision="highest"`), and `CXHRNET1` binary serialization with 64-bit FNV-1a checksum verification.
- `dataset.py`: `CXHRDAT1` binary trajectory reader/writer, contiguous `float32` sliding-window `ReplayBuffer`, and game-trajectory-aligned train/validation splitting.
- `train.py`: `@jax.jit` GPU trainer combining ridge-regularized linear subspace warm-start with AdamW/L2 updates, cosine learning-rate decay, masked policy cross-entropy, and value MSE.
- `loop.py`: Multi-generation AlphaZero orchestrator driving Rust self-play generation, JAX GPU training, numerical forward-pass parity verification against the Rust engine, and paired-opening arena gating.
- `test_pipeline.py`: End-to-end unit and GPU integration test suite covering CUDA execution, `CXHRNET1` and `CXHRDAT1` round-trips, CPU/GPU numerical parity, replay buffer windowing, and loss convergence.

## Setup

Install dependencies in an isolated environment with [`uv`](https://docs.astral.sh/uv/):

```bash
cd training
uv sync
```

Or install directly into an active virtual environment:

```bash
uv pip install "jax[cuda12]>=0.12.0.1" "numpy>=2.5.4"
```

Both `model.py` and `train.py` set `XLA_PYTHON_CLIENT_PREALLOCATE=false` and `XLA_PYTHON_CLIENT_MEM_FRACTION=0.50` before importing JAX, and enforce `jax_default_matmul_precision="highest"` to disable Ada Lovelace TF32 mantissa truncation so GPU `f32` outputs match Rust CPU `f32` inference within `< 1e-6`.

## Self-Play & Training Loop

Each generation in `loop.py` executes four stages:

1. **Self-Play Data Generation (`selfplay --datagen`)**: Plays multithreaded PUCT self-play games with root Dirichlet noise ($\alpha = 0.3, \varepsilon = 0.25$), temperature exploration over the first 12 plies, and 4-way Klein four-group ($V_4$) symmetry augmentation.
2. **GPU Training (`train.py`)**: Appends the new generation's `CXHRDAT1` file to the sliding-window `ReplayBuffer` (`250,000` samples max, `344 MB` RAM), splits trajectories at game boundaries into train and validation sets, and updates the network weights on the GPU.
3. **Forward-Pass Parity Verification (`selfplay --verify-forward`)**: Evaluates the candidate `CXHRNET1` checkpoint in Rust on states from the latest generation and asserts `max_abs_diff < 1e-5` between JAX GPU and Rust CPU policy and value outputs.
4. **Arena Gating (`selfplay --arena`)**: Plays colour-paired duplicate openings between the candidate network and the reigning best checkpoint (plus `gen_000`, `random-uct`, and `tactical-uct` baselines), promoting the candidate when its win rate meets `--promotion-threshold`.

## Binary Formats

### `CXHRNET1` Network Weights (`457,192` bytes)

Every checkpoint consists of a 32-byte little-endian header (`<8sIHHHHIQ`) followed by `114,290` little-endian `f32` parameters (`457,160` bytes):

| Offset | Type | Field | Value |
| :--- | :--- | :--- | :--- |
| `0..8` | `[u8; 8]` | `magic` | `b"CXHRNET1"` |
| `8..12` | `u32` | `version` | `1` |
| `12..14` | `u16` | `inputs` | `294` |
| `14..16` | `u16` | `hidden` | `128` |
| `16..18` | `u16` | `actions` | `49` |
| `18..20` | `u16` | `value_hidden` | `32` |
| `20..24` | `u32` | `param_count` | `114,290` |
| `24..32` | `u64` | `checksum` | 64-bit FNV-1a hash of payload bytes (`32..457192`) |

Parameters are stored in row-major `[out_dim, in_dim]` order:
`W_stem (128, 294)`, `b_stem (128)`, `W_res1a (128, 128)`, `b_res1a (128)`, `W_res1b (128, 128)`, `b_res1b (128)`, `W_res2a (128, 128)`, `b_res2a (128)`, `W_res2b (128, 128)`, `b_res2b (128)`, `W_pol (49, 128)`, `b_pol (49)`, `W_val1 (32, 128)`, `b_val1 (32)`, `W_val2 (1, 32)`, `b_val2 (1)`.

### `CXHRDAT1` Self-Play Dataset (`16 + 1,376 * N` bytes)

Each dataset file begins with a 16-byte little-endian header (`<8sII`):

| Offset | Type | Field | Value |
| :--- | :--- | :--- | :--- |
| `0..8` | `[u8; 8]` | `magic` | `b"CXHRDAT1"` |
| `8..12` | `u32` | `version` | `1` |
| `12..16` | `u32` | `num_samples` | Number of 344-float records ($N$) |

Each record contains `344` contiguous little-endian `f32` values (`1,376` bytes):
- `input[0..294]`: Six $7 \times 7$ canonical feature planes (`side_to_move` stones, opponent stones, legal move mask, normalized flip count $\min(\text{flips}, 4) / 4$, last move one-hot, and normalized ply $\text{ply} / 49$). When `side_to_move == Blue`, the board is transposed `(file, rank) <-> (rank, file)` before applying the Klein four-group ($V_4$) reflection so `side_to_move` always connects Top (`rank 0`) to Bottom (`rank 6`).
- `policy[294..343]`: Canonical MCTS root visit distribution over the 49 cells.
- `value[343]`: Terminal game outcome $z \in \{-1.0, +1.0\}$ from the perspective of `side_to_move`.

## Commands

Run the unit and GPU integration test suite:

```bash
uv run python test_pipeline.py
```

Run a multi-generation self-play, training, verification, and arena loop (automatically builds `../Cargo.toml` release `selfplay` if needed):

```bash
uv run python loop.py --generations 4 --games-per-gen 220 --datagen-sims 450
```

Train directly on one or more existing `CXHRDAT1` files:

```bash
uv run python train.py \
  --data runs/default/data/gen_001.bin \
  --weights-out runs/default/checkpoints/gen_001.bin
```
