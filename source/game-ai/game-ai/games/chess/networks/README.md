# Tiny NNUE artifacts

`tiny-v1.gainnue` is the versioned, checksummed network embedded by the
educational chess engine. It is generated by `ai-chess-nnue-trainer`; the
binary format and scalar inference implementation live in `src/nnue.rs`.

The file contains:

- magic `GAINNUE\0`;
- format version 1;
- fixed dimensions (`768 → 2×128 → 1`);
- clipped-ReLU activation id;
- feature/output quantization scales (`4096` and `64`);
- payload byte count and FNV-1a checksum;
- `i16` feature bias and feature-transformer rows;
- `i16` output weights and an `i32` output bias.

Training data and trainer state are private build inputs. Only this compact
inference artifact is intended to ship with the WASM engine.

## Reproducing `tiny-v1`

The trainer mixes two local Archon sources:

- `data/nnue/hardneg/labeled/hn_cp_wdl_filtered.txt`: 1,723,284
  `FEN | cp | result` rows, FNV-1a `b83e00ab72d28e6d`;
- `data/nnue/canon-v1/build/diag/sample_2k.tsv`: a deterministic
  every-2,000th-position sample of the broad canonical corpus, 54,854 rows,
  FNV-1a `1f84ead0c8bda1f7`.

Scores were produced by Stockfish 18 at a fixed 50,000-node limit and are
stored from White's point of view. The trainer applies each recipe's
documented output scale: `1.94` for the WDL-free hard negatives and `1.42` for
the canonical curriculum.

The runtime position parser and legal-move generator reject invalid,
in-check, tactical, promotion, duplicate, and extreme-score rows. A
position-key hash makes the split deterministic:

- 41,279 positions train weights;
- 15,903 positions select the best epoch;
- 15,982 positions form a held-out test bucket that never selects weights or
  hyperparameters.

The initial network is a material prior with one-eighth of the average tuned
middlegame/endgame piece-square adjustment. A weak pull toward that seed
discourages this deliberately hard-negative-heavy sample from erasing broad
chess knowledge. Twenty deterministic Adam epochs minimize Huber loss.

On the combined untouched test bucket, the tuned classical evaluator has
146.60/192.65 MAE/RMSE centipawns against the teacher. The final float network
scores 117.04/154.11 and its quantized runtime form scores 117.04/154.14. On
the canonical slice alone, PSQT's 117.38/161.70 becomes 108.37/147.57. The
worst float-versus-integer difference is 7.602 centipawns, below the trainer's
10-centipawn artifact gate. These are teacher-agreement measurements, not
playing strength or Elo claims.

The installed artifact is 197,412 bytes with payload checksum
`f315930090909a44`.

## Published disagreement fixture

After quantization, the trainer ranks held-out positions by absolute
PSQT/NNUE disagreement, but only retains candidates where NNUE reduces
absolute teacher error by at least 50 centipawns. The second-ranked candidate
is retained as a readable regression fixture:

```text
fen=k7/P3K3/8/8/3B4/8/8/8 w - - 67 130
teacher=+54  psqt=+616  nnue=-33
absolute gap=649  teacher-error improvement=476
```

This is a wrong-colored-bishop rook-pawn ending from the untouched test bucket;
it did not select an epoch or contribute a gradient. Its material, PSQT, and
NNUE values are recomputed by the production engine. The teacher number is a
fixed 50,000-node Stockfish label, not an exact tablebase value.
